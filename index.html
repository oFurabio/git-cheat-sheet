Git, sem mistério

Os comandos essenciais para começar, salvar e sincronizar seu projeto

Comandos essenciais

01

git init

Inicializa um repositório Git local.

02

git add .

Adiciona alterações para dar commit.

03

git commit -m "[Mensagem de Commit]"

Salva as alterações com uma mensagem descritiva.

04

git push -u origin main

Envia commits ao repositório remoto.

05

git clone [link do repositório]

Copia um repositório remoto para a máquina.

06

git fetch

Verifica se o repositório remoto contém atualizações.

07

git pull

Baixa e aplica as atualizações do repositório remoto.

08

git remote add origin [link do respositório]

Conecta o repositório remoto ao repositório na máquina.

Use mensagens de commit curtas, claras e escritas no imperativo.
